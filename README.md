# 주식회사 정원푸드 (Jungwon Food Co., Ltd.)

## 프로젝트 소개
주식회사 정원푸드의 공식 웹사이트입니다. 30년 전통의 김치 생산 전문 기업으로, 해외수출 중견 김치공장의 위상을 갖춘 **단일 페이지(Single Page)** 웹사이트입니다.

## 특징
- **모바일 퍼스트 디자인**: 스마트폰 화면에 완벽히 최적화된 반응형 웹사이트
- **단일 페이지 구조**: 모든 내용이 하나의 페이지에 스크롤 형식으로 구성
- **세련된 컬러 톤**: 버건디(Burgundy) & 딥그린(Deep Green) 톤앤매너
- **고품질 이미지**: Unsplash 무료 고화질 샘플 이미지 사용
- **완전한 반응형**: 모바일, 태블릿, 데스크톱 모든 디바이스 지원
- **모바일 고정 바**: 전화상담(1877-5923) 및 견적신청 바로가기

## 사이트 구조

### 단일 페이지 섹션
**index.html** - 모든 콘텐츠가 포함된 단일 페이지

1. **Hero Section (#hero)**
   - 30년 전통의 손맛
   - 해외수출 중견 김치공장
   - 슬로건: 맛·신선도·청결·신뢰

2. **About Section (#about)**
   - 회사 소개
   - 핵심 강점 카드 (30년 전통, 해외 수출, 저온발효 기술)

3. **Master Craftsman**
   - 채남기 생산총괄 대표 소개
   - 30년 경력의 김치생산 장인
   - 유명 셰프 극찬 및 제자 양성

4. **Core Technology**
   - 저온발효 기술 (묵은지·숙성지 특화)
   - 포장용기 접목 기술 (장기보관 특화)
   - 수출 특화 기술 (해외 시장 대응)

5. **Products Section (#products)**
   - 주력 제품: 묵은지(시그니처), 포기김치, 열무김치, 갓김치
   - 기타 제품: 깍두기, 총각김치, 백김치

6. **Distribution**
   - 프랜차이즈 납품
   - 식자재 도매
   - 온라인몰 (김치광장)
   - 해외 수출 (미국·캐나다)

7. **Contact Section (#contact)**
   - B2B 대량납품 및 수출 견적 문의 폼
   - 실시간 입력 검증
   - 전화번호 자동 포맷팅

8. **Footer**
   - 회사 정보
   - 지도 링크

9. **Mobile Fixed Bottom Bar**
   - 전화상담 버튼 (1877-5923)
   - 견적신청 버튼

### 디렉토리 구조
```
Jungwon Food/
├── index.html       (단일 페이지 - 모든 콘텐츠 포함)
├── css/
│   └── style.css    (통합 스타일시트)
├── js/
│   └── main.js      (JavaScript 기능)
└── README.md
```

## 기술 스택
- **HTML5**: 시맨틱 마크업, 단일 페이지 구조
- **CSS3**: CSS Variables, Flexbox, Grid, 반응형 디자인
- **JavaScript (Vanilla)**: 스크롤 네비게이션, 섹션별 활성화, 폼 검증
- **Google Fonts**: Noto Sans KR
- **Unsplash**: 고화질 무료 이미지

## 주요 기능

### 1. 단일 페이지 스크롤 네비게이션
- 부드러운 스크롤 애니메이션
- 섹션별 자동 메뉴 활성화
- 앵커 링크 (#hero, #about, #products, #contact)

### 2. 반응형 네비게이션
- 모바일: 햄버거 메뉴
- 데스크톱: 가로형 메뉴
- 스크롤 시 헤더 고정

### 3. 히어로 섹션
- 풀스크린 배경 이미지
- 오버레이 효과
- CTA 버튼 (제품 보기, 견적 문의)

### 4. 애니메이션
- Intersection Observer를 이용한 스크롤 애니메이션
- 호버 효과
- 부드러운 전환 효과

### 5. 견적 문의 폼
- 실시간 입력 검증
- 이메일 형식 체크
- 전화번호 자동 포맷팅 (010-0000-0000)
- 필수 항목 체크

### 6. 모바일 고정 바
- 하단 고정 2버튼 레이아웃
- 전화상담 (tel: 링크로 바로 다이얼)
- 견적신청 (스크롤로 문의 폼 이동)
- 태블릿/데스크톱에서는 숨김

## 설치 및 실행
웹사이트는 정적 파일로 구성되어 있어 별도의 설치가 필요없습니다.

### 방법 1: 직접 열기
`index.html` 파일을 더블클릭하여 브라우저에서 바로 열기

### 방법 2: 로컬 서버 실행 (권장)
```bash
# 프로젝트 폴더로 이동
cd "C:\Users\Lenovo\Desktop\Jungwon Food"

# Python 3
python -m http.server 8000

# Node.js (npx를 사용한 http-server)
npx http-server -p 8000
```

그 후 브라우저에서 `http://localhost:8000` 접속

## 사용 방법

### 네비게이션
- 상단 메뉴 클릭 시 해당 섹션으로 부드럽게 스크롤
- 모바일: 햄버거 메뉴 → 원하는 메뉴 선택
- 현재 보고 있는 섹션이 메뉴에 자동 표시

### 전화 상담
- 모바일 하단 고정 바의 "전화상담" 버튼 클릭
- 또는 푸터의 전화번호 클릭
- 스마트폰에서 자동으로 다이얼 화면 실행

### 견적 신청
- 모바일 하단 고정 바의 "견적신청" 버튼 클릭
- 또는 상단 메뉴에서 "견적문의" 선택
- 견적 폼으로 자동 스크롤 이동

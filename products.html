시그니처

묵은지 (숙성김치)

정원푸드의 대표 제품으로, 국내 최고 수준의 저온발효 기술로 오랜 시간 숙성시켜 깊고 진한 맛을 완성했습니다.

  • ✓ 국내 최고 수준의 저온발효 기술
  • ✓ 깊고 진한 숙성의 맛
  • ✓ 찌개, 국물요리에 최적
  • ✓ 해외수출 인증 제품

포기김치

신선한 배추와 엄선된 양념으로 만든 전통 포기김치입니다. 아삭한 식감과 감칠맛이 일품입니다.

  • ✓ 신선한 국내산 배추 사용
  • ✓ 전통 방식의 양념
  • ✓ 아삭한 식감 유지
  • ✓ 단체급식 및 프랜차이즈 납품

열무김치

여름철 별미로 사랑받는 열무김치입니다. 시원하고 상큼한 맛이 입맛을 돋웁니다.

  • ✓ 신선한 열무 사용
  • ✓ 시원하고 아삭한 식감
  • ✓ 여름철 인기 제품
  • ✓ 국수, 냉면과 찰떡궁합

갓김치

매콤하고 알싸한 갓의 풍미가 살아있는 갓김치입니다. 고기요리와 함께하면 더욱 맛있습니다.

  • ✓ 신선한 갓 사용
  • ✓ 매콤하고 알싸한 풍미
  • ✓ 고기요리와 궁합
  • ✓ 전라도 전통 방식
